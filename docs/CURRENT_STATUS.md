# 현재 기능 상태 — 2026-09-29

## 구현 및 검증

- 이메일/비밀번호 회원가입, 세션 복원, 로그아웃. AUTH_CREDENTIALS에 비밀번호 해시 저장.
- 가입 후 회사 생성(사장) 또는 일회성 초대 참여(직원). 회사 간 접근 제한.
- 사장은 회사 출장 조회, 직원/부장은 본인만. 다른 사람 일정 수정은 사장도 불가.
- AWS Oracle 기반 출장 생성·조회·수정·삭제, 체크인/경비 저장. 오류를 성공으로 처리하지 않음.
- 서버 GPS 거리 계산/등록 태그 검증. 임의 좌표·모의 태그로 현장 인증 성공 처리하지 않음.
- 영수증 분석 후 사용자 확인, JPY 경비 검증. AI 오류를 샘플 경비로 대체하지 않음.
- 보고서 저장/DOCX 생성. 제로보 일보는 별도 테이블에 기록 기반으로 저장.
- 제로보 작업 API, 회사 권한·중복 요청 방지. 제공자 대체 테스트로 노진아/김행진 계정 실DB 검증 완료.
- 프런트 타입/빌드/회귀 검사, Android Capacitor 동기화는 9월28일 통과. 실제 기기 검증과 구별해야 함.
