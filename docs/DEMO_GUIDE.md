## 성공과 미검증을 구분해서 설명하기

- GPS 체크인 후 NFC+GPS 체크아웃에 성공했다. 체크인도 NFC로 했다고 소개하면 안 된다.
- 10:10 일보에는 당시 16:00 일정이 보인다. 이후 13:25 구간에서 16:30으로 변경했고 마지막 메일에는 변경된 시간이 반영됐다.
- Gmail은 첫 시도에서 결과 확인 오류가 있었고, 사용자 재연결 후 새 발송으로 실제 수신과 Word 첨부가 확인됐다. 오류가 전혀 없었던 시연으로 편집 설명하지 않는다.
- 도로 경로는 예상 경로이며 실제 이동 궤적이 아니다.
- 영수증 화면과 저장된 수동 경비는 OCR 성공 증거가 아니다. 실제 사진 인식은 미검증이다.
- 사용자가 발화할 수 없어 텍스트로 진행했다. 음성 인식·백그라운드 호출 성공 장면은 없다.
- 관리자 통계 표시와 발송 상태 복원 오류는 알려진 후속 수정 대상이다.
- 설정/회원가입/도움말 화면을 보여 줬다는 것과 해당 기능의 모든 과정을 실행했다는 것은 다르다.
