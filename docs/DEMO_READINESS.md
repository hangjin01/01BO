## 우선 검증 순서

1. 본인 계정 로그인 → Gmail 연결 → 명시 승인한 테스트 메일 수신 확인.
2. 장소 검색 결과 선택 → 일정 저장 → 재로그인 후 저장값 확인.
3. 실제 기록으로 일보 생성 → Word 열어서 한글/일본어/페이지 확인.
4. 직원 본인 출장과 사장 회사 출장 권한 비교, 타회사 차단.
5. 제로보 일정/일보 도구 실행, Luna 지연 시 진행 상태와 재시도 중복 방지.
6. 발표용 실기기에서 로그인·위치·파일 공유·Gmail 인증 확인. PC localhost 테스트와 구분.
