# 구현 및 검증 상태 — 2026-09-25

검토 기준: 사용자가 제공한 O1BO_technical_review.md. 문서는 참고 자료이며 현재 코드와 대조했다. 사용자의 요청에 따라 AWS 연결은 후속 작업으로 남겼다.

## 수정한 프런트엔드

- App 문법 오류·누락 핸들러·Lang/Vite 타입 복구, typecheck/test 명령 추가.
- GPS 서비스 호출 규격 수정, 위치 실패 시 일정 좌표로 인증하는 동작 제거, 잘못된 좌표를 도쿄 좌표로 바꾸지 않음.
- AI 실패 시 가짜 영수증/출장/보고서 반환 제거. 요청은 서버 프록시 계약으로 이관. 생성 취소는 AI 요청을 중단하며 아직 저장 전이면 결과를 저장하지 않음. 이미 전송된 저장 요청을 취소/롤백하는 기능은 아님.
- 다일 일정의 날짜·좌표 보존, 잘못된 좌표는 개별 주소로 검색, 기간·시간·중복 ID 검증.
- 수정 시 PUT, 삭제 시 DELETE, 보고서 저장 시 실제 저장 응답 확인. 실패하면 기존 화면 데이터를 유지.
- 게스트 출장·근태·경비 복원, 업무 데이터 서버 요청 분리. 닉네임·언어·테마·NFC 설정 저장.
- 영수증 분석 후 수정/확인 모달, JPY 금액/날짜 검증, 직접 경비 입력, 출장별 경비 조회·삭제.
- 보고서는 선택한 출장의 근태·경비만 전달. HTML 입력 escape. Word 내보내기는 실제 DOCX ZIP/XML(평문 문단; Markdown 고급 스타일은 미지원).
- 지도 팝업의 문자열 escape, 가짜 날씨/실시간 인증 표시 수정.
- 일반 로그인은 서버 세션 조회, 프로필·회사·팀 변경은 서버 검증 API 계약 사용.
- 이메일 타이머 성공 제거, 서버 발송 API 응답 확인.
- NFC 스캔 중단 처리, 빈 태그 처리, 모의 스캔은 게스트만 허용. 음성 버튼은 실제 일회성 음성 입력 시작/중지로 연결.

## 확인한 범위

- 타입 검사·회귀 테스트·Vite 프로덕션 빌드 최종 통과. JS 번들 500kB 초과 경고는 남아 있음.
- 자동 회귀 검사: 좌표·거리, 잘못된 날짜/일정 시간/기간, 다일 일정·개별 좌표·중복 ID, HTML escape, API 수정/삭제 계약 및 실패 전파, AI 실패 시 샘플 미반환, 주소 검색 실패, DOCX ZIP CRC/XML/한일 텍스트.
- 로컬 브라우저: 게스트 로그인, 경비 직접 입력·저장, 새로고침 후 경비 복원. 보고서 수동 편집·저장·새로고침 후 복원과 HTML 태그의 텍스트 표시도 확인.
- AWS/Oracle, 실제 AI, 이메일, 휴대폰 NFC/위치, Word 앱 렌더링은 미검증.
