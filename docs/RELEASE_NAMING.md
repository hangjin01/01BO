# 앱 빌드·릴리즈 이름 규칙

사용자 지정(2026-10-10): APK 파일 이름은 `01bo-v{버전}.apk`.

- 큰 기능 변경: `v0.1 → v0.2`
- 작은 기능 변경: `v0.1 → v0.11`
- 버그 수정: `v0.11 → v0.111`
- 정식 출시: `v1.0`

현재 사용자가 지정한 기준 버전은 **v0.3**(제로보 호출 설정 추가).
바로 전 지도·이메일 확인 수정본은 `01bo-v0.2.apk`로 이름을 변경한다. 그 이전 기록 APK는 보존한다.
Android versionCode는 별도 단조 증가 정수다. v0.3은 versionCode 3, versionName 0.3이다. 이전 APK는 이름만 변경하므로 내부 메타데이터는 유지한다.
