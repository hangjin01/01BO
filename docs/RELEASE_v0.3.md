# 01bo-v0.3 — 제로보 호출 설정

Android 설정에서 백그라운드 제로보 호출을 켜고 끌 수 있습니다. 기본은 꺼짐입니다. 켜면 마이크·알림 권한을 요청하고 한국어 호출 감지를 휴대폰에서 실행합니다.

- ‘제로보’라고 부르고 잠시 기다리면 응답음과 알림 표시.
- 앱이 열려 있으면 대화창 표시, 백그라운드에서는 알림을 눌러 대화 재개.
- 설정/알림에서 끄기, 최대30분 자동 종료. 음성 입력 시작·로그아웃·앱 종료 시 대기 중단.
- 대기 음성은 저장하거나 서버로 전송하지 않음.
- 기존 지도 보완, 일정/일보 요청, 이메일 발송 최종 확인 포함.

한국어 실험 기능이며 일본어 호출 감지와 백그라운드 업무 자동 실행은 아직 지원하지 않습니다. 배터리를 사용하고 절전/강제 종료로 중단될 수 있습니다. 실제 단말 인식률·권한·잠금 동작은 설치 후 검증이 필요합니다.

타입검사, 웹/Android 빌드, 호출어 단위검사, 모델 로딩·무음 확인, 서명/ZIP 정렬 검사를 통과했습니다. 연결된 Android 실기기는 없었습니다. 파일 약140MB.
