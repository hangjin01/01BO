# 제로보 백그라운드 음성 호출 계획 — 2026-10-10

상태: v0.3에 한국어 실험 기능 구현. 기본 OFF, Android 마이크 foreground service, 최대 30분 대기, 설정/알림 종료, 로그아웃 및 앱 작업 종료 시 정지.

현재 범위: Vosk 로컬 모델이 ‘제로 보’ 발화를 감지하면 응답음과 알림을 표시한다. 앱이 열려 있고 잠금 해제 상태면 제로보 대화창을 연다. 백그라운드에서는 사용자가 알림을 눌러 대화를 이어간다. 음성 입력을 시작하면 호출 서비스는 마이크를 해제하며 다시 수동 ON이 필요하다.

아래 계획의 **백그라운드 명령 인식·자동 서버 요청은 아직 미구현**. 현재 호출은 업무 실행/이메일 발송을 하지 않는다. 녹음 원본/인식 문장 저장·서버 전송 없음.

모델: Apache-2.0 vosk-model-small-ko-0.22 + Vosk Android 0.3.75 + JNA 5.18.1. APK에 모델 포함(약 140MB APK, 최초 활성화 시 앱 전용 저장소로 복사). 다시 빌드할 때 `python3 scripts/prepare-wake-model.py` 실행. 공식 ZIP SHA-256 검증. API 키/계정 불필요. ‘제로보’ 자체는 사전에 없고 ‘제로’/‘보’가 있으므로 해당 구문과 <UNK> 거절 경로로 한정, 단어 confidence 0.8 이상, 연속 호출 10초 억제. 전용 저전력 하드웨어 모델이 아닌 로컬 음성 인식 기반 실험 구현이다.

검증: 타입/웹 빌드, Android 컴파일, 호출어 단위검사, 실제 모델 로딩·사전·무음 입력 확인. 연결된 ADB 기기가 없어 실제 발화·배터리·화면 잠금/절전 테스트 미실행. 오인식률 보장 금지.

남은 실제 기기 검증: 권한 거부→OFF 유지, ON→준비→대기, ‘제로보’ 발화 후 알림/응답음, 잠금 상태에서 화면 강제 실행 없음, 알림 끄기→마이크 표시 해제, 재진입 실제 OFF, 로그아웃 및 앱 종료, 30분 만료.

## 사용자 흐름

1. 설정의 ‘백그라운드 제로보 호출’은 기본 OFF. 사용자가 앱을 연 상태에서 ON을 누르고 마이크·알림 권한을 허용하면 시작한다. 거절하면 OFF 유지.
2. 상시 알림에 ‘제로보 호출 대기 중’ 및 ‘끄기’ 동작을 표시한다. 설정 OFF, 알림 끄기, 로그아웃 시 마이크·서비스를 즉시 해제한다.
3. 휴대폰 안에서 ‘제로보’ 호출어만 감지한다. 호출 전 음성을 서버로 보내거나 보관하지 않는다. 실제 한국어 호출어 모델과 라이선스는 선정·검증 필요.
4. 호출 감지 → 짧은 응답음/진동 → 명령을 제한 시간 동안 인식 → 기존 인증된 에이전트 요청. 사용자에게 명령 전송 시점과 음성 인식 제공자를 안내한다.
5. 이메일은 수신자·내용·첨부 미리보기까지만 준비한다. 앱에서 ‘정말 보내겠습니까?’ 확인 후 발송한다. 잠금 상태에서는 개인 업무 내용 낭독 없이 앱에서 잠금 해제 후 확인한다.

## 구현 순서

- 한국어 로컬 호출어 모델 후보 선정과 실제 Android 기기에서 오인식·누락·배터리 측정. 기존 Google 음성 입력 화면을 반복 실행하는 방식은 쓰지 않는다.
- Android microphone foreground service, RECORD_AUDIO / FOREGROUND_SERVICE / FOREGROUND_SERVICE_MICROPHONE 및 알림 권한·채널 구성. 앱이 보이는 동안 명시적으로 시작. 재부팅·강제 종료 후 자동 마이크 시작을 가정하지 않는다.
- Capacitor 상태 조회/시작/종료 브리지 및 설정 화면. 저장된 희망 설정 대신 실제 서비스 상태를 표시한다.
- 앱 WebView가 정지해도 동작할 인증·명령 요청 경로, 중복 요청 방지와 만료 처리 마련. 앱 화면을 백그라운드에서 강제로 열지 않고 알림을 통해 복귀.
- 호출 감지 중 명령 인식으로 마이크 전환, 타임아웃 후 대기로 복귀. 통화·다른 마이크 앱·권한 회수 시 중단과 상태 반영.
- 화면 꺼짐/잠금/절전/오프라인/로그아웃/프로세스 종료와 한국어·일본어 단말 검증 후 실험 기능으로 배포.
